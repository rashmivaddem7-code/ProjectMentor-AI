Build a complete, modern, responsive full-stack web application called:

**“ProjectMentor AI – AI Project Idea Generator & Final-Year Project Mentor”**

The purpose of this application is to help final-year college/university students discover, plan, develop, and improve software/AI projects based on their skills, interests, academic specialization, available time, team size, budget, and preferred technologies.

The application should feel like a real production-ready startup product, not a basic student demo.

==================================================

1. CORE OBJECTIVE
   ==================================================

Create an AI-powered platform where a student can:

1. Create a student profile.
2. Enter their programming skills.
3. Enter technical interests.
4. Select their academic specialization.
5. Select preferred technologies.
6. Specify whether they are working individually or in a team.
7. Specify project duration.
8. Specify project difficulty.
9. Specify available budget.
10. Generate personalized final-year project ideas.
11. View detailed explanations of each generated project.
12. Ask an AI mentor questions about a selected project.
13. Generate project architecture.
14. Generate required features.
15. Generate development milestones.
16. Generate database/schema suggestions.
17. Generate technology-stack recommendations.
18. Generate implementation guidance.
19. Generate testing strategies.
20. Generate possible future enhancements.
21. Generate project documentation content.
22. Save favorite projects.
23. Compare multiple project ideas.
24. Track project development progress.
25. Regenerate/improve an existing project idea.

3. TECHNOLOGY REQUIREMENTS
==========================

Use a modern web application architecture.

Preferred stack:

Frontend:

* React
* TypeScript
* Tailwind CSS
* Modern responsive UI
* Lucide icons or another clean icon library

Backend:

* Use the appropriate backend/API architecture supported by Google AI Studio.
* Keep the code modular and maintainable.

AI:

* Integrate Google Gemini API.
* Use Gemini for project generation, project analysis, mentoring, recommendations, and documentation generation.

Data:

* Use a persistent database if supported.
* If database integration is not immediately available, create a clean data-access layer that can later be connected to Firebase/Firestore.

Authentication:

* Provide a clean authentication architecture.
* If authentication is available, support Google/email authentication.
* If authentication cannot be configured automatically, implement a demo/local authentication flow and clearly separate it from production authentication.
